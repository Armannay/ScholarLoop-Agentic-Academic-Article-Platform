# IEEE citation guidance

Use bracketed numeric markers such as [1] in order of first appearance. Reuse the same number every time a source is cited; do not renumber it when a later paragraph changes. Place a marker next to the claim it supports and keep punctuation consistent with the selected IEEE convention.

Each number must map to exactly one SourceCard id. Build the reference list from verified cards in numeric order. Never infer author names, title, publication details, page numbers, DOI, or URL. If card metadata is missing or verification is unknown, flag the reference for resolution rather than fabricating a complete entry.
