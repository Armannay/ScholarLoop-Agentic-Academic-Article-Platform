# APA 7 citation guidance

Use author-date markers in text, matching the names and year recorded on the SourceCard. For two authors, include both surnames; for three or more authors, use the first surname followed by “et al.” from the first citation. Distinguish same-author, same-year works only when the cards provide enough metadata.

Every marker must map to a SourceCard id. The reference list is generated from verified cards; do not hand-write missing bibliographic fields, DOIs, or URLs. If author or year data is absent or ambiguous, flag the citation for user input instead of guessing. Keep punctuation and placement consistent with the surrounding sentence and the requested APA 7 style.
